# 苹果预购助手（中国大陆）

[下载最新 Mac 版本](https://github.com/YUANSHAN122/apple-preorder-helper/releases/latest/download/ApplePurchaseHelper-macOS-universal.zip) · [查看所有版本](https://github.com/YUANSHAN122/apple-preorder-helper/releases)

下载后解压，双击“苹果预购助手.app”打开，无需安装依赖。

1. 选择夜空色或星光白色，以及 256GB、512GB、1TB 或 2TB。
2. 默认开售时间为北京时间 2026-10-16 20:00:00，可以修改。
3. 如果希望程序尝试点“加入购物袋”，勾选对应选项；不勾选时仅提醒。
4. 点击“开始倒计时”，官网会在右侧打开。程序保持运行、电脑联网并开盖。
5. 到开售时间后，程序每 8 秒最多刷新一次，10 分钟后停止。发现可用按钮后提醒或尝试加购一次，然后停止自动操作。
6. 你需要确认颜色、容量、价格、购物袋结果，再自行完成结账付款。需要登录、验证码或进一步配置时，请暂停并手动操作。如果内置网页无法登录，可用“默认浏览器打开所选规格”，但默认浏览器中的页面不受本程序控制。

“暂停 / 接手操作”或关闭窗口可停止。程序运行时阻止闲置休眠，停止后恢复；合盖、断网、关机仍会影响运行。时间依赖本机时钟，请开启 macOS 的自动日期与时间。

本程序是预购辅助工具，没有经过真实开售或下单验证，不保证库存或抢购成功。当前预售页面还没有加入购物袋按钮，开售后的页面可能需要手动配置。程序只有在苹果大陆产品页的标题与所选颜色、容量都匹配、且恰有一个可见且启用的“加入购物袋”按钮时才尝试点击；未实现库存接口、绕过排队或验证码、自动付款。

规格链接及预售时间核对来源（2026-10-15）：
https://www.apple.com.cn/shop/buy-iphone/iphone-duo

源代码：main.swift。检测逻辑测试：应用内可执行文件加 --self-test 参数。

## 下载与系统要求

到本仓库 Releases 下载 `ApplePurchaseHelper-macOS-universal.zip`。要求 macOS 13 或更高，支持 Apple 芯片和 Intel。此应用只有本地临时签名，未经过 Apple 公证，系统可能阻止直接打开；可以审阅源码后自行编译，无需关闭 Gatekeeper 或其他系统保护。

## 从源码构建

需要 Xcode Command Line Tools。在仓库目录运行：

```sh
bash build.sh
```

输出在 `dist/`。检测测试覆盖规格链接、北京时间、按钮禁用、验证码、错误规格和付款按钮不被点击等场景。测试不代表官网开售后的加购成功。
